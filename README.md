# Smaller Challenger Playbook Course Site

A lightweight, single-page course website that turns playbook chapters into an interactive learning experience.

## Run locally

Because this is a static site, you can open `index.html` directly in your browser, or run a tiny local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Customize with source material

1. Open `script.js`.
2. Replace the chapter data in the `chapters` array with real chapter/section summaries from the source PDF.
3. Extend with quizzes, checkpoints, and downloadable worksheets.

Source PDF:
https://smaller-agency.github.io/docs/Smaller_ChallengerPlaybook_V9.pdf
